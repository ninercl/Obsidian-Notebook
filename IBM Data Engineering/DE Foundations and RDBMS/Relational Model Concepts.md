Relations

- Is a mathematical concept based on sets
- Describes the connection between elements of sets
- Are crucial in set theory and logic. 

- Binary relations: Establishes a connection between two elements. 3<5
- Ordered pairs: Subset of the Cartesian product. Represents binary relation.

Properties of relation:
Reflexibity: Each element relates to itself. Ex: a=a
Symmetry: B relates to a. b-->a 
Transitivity: A related to b, b related to c. ex. a < b  
									b < c  = a < c 

Antisymmetry: a to be equal to b. ex. a <= b

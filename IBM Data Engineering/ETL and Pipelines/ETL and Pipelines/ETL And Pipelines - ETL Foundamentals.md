- Extract Transform and Load: automated data pipeline engineering methodology
- Extract: Extracting the data from a source, Transformation: wrangles the data into a format that is suitable for the destination, Load:  Loading data into a database, data warehouse or other storage. 

- Examples of extraction: Web scraping, connecting programmatically via APIs
- Data Transformation: Cleaning, filtering, joining , feature engineering, formatting and data typing. 
- Load: applications may include dashboards, reports, and advanced analytics

---
ELT basics

- Extract the data from sources
- Load: takes the raw data 
- Transformation: transforming data on demand 

Use cases
- Demanding  scalability requirements of Big Data
- Streaming analytics
- Integration of highly distributed data sources

ELT is an emergin trend 
- Separates the data pipeline from the processing
- more flexibility
- No information loss

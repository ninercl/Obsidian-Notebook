Dom is the programming interface between HTML or XHTML and JavScript.
- Each DOM levels provide a detailed set of features
- Different browsers have different levels of compatibility with the DOM standard

Dom for browsers is a hierarchy that includes objects, which perform different functions. E.g. window, location, screen, and document objects.

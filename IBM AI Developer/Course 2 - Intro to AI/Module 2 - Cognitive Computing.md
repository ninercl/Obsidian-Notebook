## Neural Networks 
#neuralnetworks 


Neural networks: Human brain
- Face recognition
- Self-driving cars

- Neural networks are computational models influenced by the human neural structure 
- An artificial neural network consists of interconnected nodes know as neurons. 

![[Pasted image 20260930001026.png|479]]


- Forward propagation: Data processing from input to output layers.
- Backpropagation: Internal parameters adjusted based on loss. 


![[Pasted image 20260930003549.png|463]]

![[Pasted image 20260930003607.png|464]]


The repetition of forward pass, error calculation, and backward pass produce accurate predictions. 

- Perceptron NN: Siples one, consists of input layer and output layer
- Feed-forward neural networks: Information flows in one direction, that is, forward. Each neuron in a layer receives input from neurons in the previous layer and then passes its output to neurons in the next layer.
- Deep feed-forward network: is similar to feed-forward network with just more than one hidden layer. 
- Modular neural network: combines two or more neural network to arrive at the imput.
- Convolutional Neural Network: is a type of neural network that is well suited for analyzing visual data. A convolution refers to the mathematical operation where a function is applied to another function, and the result is a mixture of the two functions. 
- Recurrent Neural Networks: Each of the neurons hidden layers receives an input with an specific delay in time. This allows the RNN to consider the context of the input.

Deep learning: neural network is considered a deep network when if it consists more than 3 layers (including input and output layers)

## *Generative AI models*
#genaimodels

- They area a class of artificial intelligence systems. 
- Recognize patterns and trends. Machine learning algorithms and deep learning techniques. They generate new content. 



VAE works by transforming input data through encoding/decoding. 

- Encoder: Convers input to latent space representation
- Latent space representation: Captures key features data
- Decoder: Generates new outputs based on latent space representation

VAEs application:
- Image generation
- Anomaly detection

GANs

- GANs involve two neural networks 
	- Generator: Generates new data samples
	Creates data that looks real
	- Discriminator: Verifies generated data. 
	Verifies generated data. Discriminator tries to tell the difference between real and fake data. 

GANs applications:
- Image synthesis
- Style transfer 
- Data augmentation 
- StyleGan

Autoregressive Models:
- Context of previously generated elements
- Prediction of next elements in sequence

Autoregressive applications:
-Generate sequences of data like text or music. 

Transformers are generally used in NLP tasks
- work with encoder/decoder layers -> text sequences

Categories of Generative AI

Unimodal: generates outputs withing the same modality
Multimodal: handles inputs from one modality, and produces outputs in a different modality.

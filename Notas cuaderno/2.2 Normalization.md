
Normalization is the process of organizing your data to reduce redundant data.
Increases speed if transaction and improves the integrity of data. 

**First Normal Form**

- Each row must be unique
- Each cell must contain only a single value
- Also called 1NF

**Second normal form**

- Database must be in the first normal form
- Create separate tables for sets of values
- Also called 2NF

**Third normal form**

- Database must be in the first and second normal form
- Eliminate columns that do not depend on the key
- Also called 3NF

* Transactional benefits from 3NF while Analytical from 1NF

Constraints

Relational data model needs to adhere to rules using:

- Entity Integrity constraing: The primary key is a unique value that identifies each tuple (or row) in the table. (Should not be NULL)
- Referential integrity constraings: specifies the relationship which exists between tables
- Semantic integrity cosntraints: enforces the correctness of the meaning of the data
- Domain constraint: ensures that valid values are entered for a given attribute
- Null constraint: Ensures that attribute values should not be null
- Check constraints: limits the values that are  accepted by an attribute.
